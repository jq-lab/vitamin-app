## 1. 产品定位

Vitora 是一款私密的 iOS 身体节律陪伴 App。它服务的是想看懂自己每日身体状态、但不想被任务系统推着走的年轻女性。

核心用户通常是 22-35 岁，可能有 Apple Watch 或其他健康数据来源，也可能只做轻量手动记录。她们可以看到睡眠、HRV、心率、周期、情绪等很多原始信息，但真正的问题不是“我有多少数据”，而是：

> 今天我怎么样？我可以轻轻试什么？

Vitora 的角色不是医疗诊断工具，也不是 Apple Health 式指标 dashboard。它是用户面对的 AI assistant：把健康数据、周期上下文、用户补充和晚间反馈翻译成可理解的每日状态，并从用户选择和反馈中学习。

## 2. 核心功能

Vitora 当前 P0 Swift App 围绕一个最小学习闭环展开：

1. 早晨，Vitora 给出今日状态和一个清晰下一步。
2. 白天，用户正常生活，需要时轻量补充一件重要变化。
3. 建议出现时，Vitora 给出很小的当日行动，而不是任务清单。
4. 晚间，Vitora 回访今天发生了什么，对比建议前后的感受。
5. 次日，Vitora 根据反馈让建议更贴近用户。

当前核心模块：

| 模块 | 作用 |
| --- | --- |
| Onboarding | 收集最小称呼、周期上下文、关注点和 HealthKit 选择；用户可跳过 HealthKit。 |
| Today | 展示今日状态、身体要素和 Vitora 今日建议，是默认启动主区。 |
| Today 周期日历 | 从 Today 顶部进入，解释今天在周期时间线中的位置。 |
| Energy / Orb | 作为下拉、每日首次或晚间复盘里的隐藏仪式层，不常驻抢占首页。 |
| Vitora Tab | 全局 AI assistant surface，包含 Pixel Vitora、上下文、对话、快捷问题、快捷上下文 chips 和输入 dock。 |
| Contextual Vitora Sheet | 从状态卡、身体要素、建议、周期等来源唤醒，保留来源上下文。 |
| Cycle | 展示长期节律背景、当前周期阶段与今天的关系，以及能量动态；不做日历首页。 |
| Evening Review | 晚间复盘当天建议或记录是否有帮助，形成学习信号。 |
| Support / Settings | 管理个人资料、数据来源、营养补给、提醒、导出、隐私法律和账号移除。 |

## 3. 市场定位方向

当前 repo 没有单独成稿的外部市场规模或竞品分析文档。因此本节只记录内部市场定位方向，不伪造竞品数据或市场数字。

Vitora 的定位方向是：

> AI companion + 女性身体节律理解 + 低压力日常建议。

它与常见健康产品的区分点：

| 常见方向 | Vitora 的选择 |
| --- | --- |
| 医疗诊断 / 症状判断 | 不做诊断，不制造病理化和恐慌感；只提供生活方式参考和低压力解释。 |
| 打卡 / 任务 / 连续天数 | 不做打卡循环、不做完成率、不用红点和连续天数制造压力。 |
| Apple Health dashboard | 不要求用户自己读懂大量指标；Vitora 负责解释“这些数据对今天意味着什么”。 |
| 周期日历工具 | 周期是理解今天和长期节律的上下文，不把 Cycle 首页做成日历。 |
| 通用聊天机器人 | Vitora 不是泛聊天；它围绕身体状态、周期、记录、建议和复盘工作。 |
| 购买转化漏斗 | 不把健康焦虑包装成订阅转化；P0 不做完整 VIP 体系。 |

设计和体验上，Vitora 走的是 Aura Glass Pixel Companion：浅蓝/青色弥散背景、清透玻璃层级、Pixel Vitora 品牌 IP、温和但可执行的解释和建议。

## 4. 产品想法如何演变到现在

Vitora 当前形态来自一次产品 reset，而不是旧 App 的直接复刻。

早期方向里有更多功能池、抽屉入口、记录路径、旧 Luna 命名和 RN / Expo 实现痕迹。重建时，这些内容被重新筛选：

| 阶段 | 变化 |
| --- | --- |
| 旧 Luna / RN 阶段 | 有 AI 管家、记录、周期、健康数据等意图，但入口多、页面密度高，容易变成功能集合。 |
| Product Reset | 明确产品不复刻旧 RN，不追求全量 parity，只保留能证明 Vitora 成立的最小闭环。 |
| 角色重命名 | 用户面对角色统一为 Vitora；`Luna` 只作为历史证据或内部迁移债务。 |
| 三主区收敛 | 主导航固定为 Today / Vitora / Cycle，不新增第四个主 Tab。 |
| Today 收敛 | Today 从记录和指标堆叠，收敛为“现在状态 -> 身体要素 -> Vitora 今日建议”。 |
| Vitora 升级 | Vitora 从普通聊天入口，升级为全局 assistant layer 和 contextual sheet。 |
| Cycle 纠偏 | Cycle 不再做日历首页，而是长期节律背景和能量动态。 |
| 视觉系统确定 | 从偏 Apple Health / 普通白卡方向，转向 Aura Glass + Pixel Vitora IP。 |
| 学习闭环确定 | 当日建议必须连接提醒偏好和晚间复盘，形成次日更贴近用户的学习信号。 |

最终，Vitora 的当前 App 目标不是“功能最多的女性健康工具”，而是一个能在每天几秒内回答用户核心问题的身体节律陪伴系统：

> 我今天怎么样，以及我可以轻轻试什么？

## 反向边界

Vitora 不能成为：

- 医疗诊断产品。
- 打卡、todo、连续天数或完成率产品。
- 需要用户自己读懂大量指标的 dashboard。
- 套了女性健康主题的泛用聊天机器人。
- 伪装成健康陪伴的购买转化漏斗。
- 旧 RN / Expo 版本的视觉和路由复刻。
