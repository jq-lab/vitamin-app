# Vitora 花园玩法 · 视频机制参考规划

> 来源视频：`录屏2026-05-20 09.54.24.mov`  
> 状态：玩法规划草案  
> 目标：吸收视频里的“轻揭示、收集反馈、记录回流”机制，把它转译成 Vitora 的花园轻证据层；不引入抽卡、货币、稀有度、连续打卡或任务压力。

## 1. 视频玩法拆解

视频里的核心体验不是复杂养成，而是一个很短的收集闭环：

```text
主网格
  展示一组已拥有 / 可获得的像素宠物
  底部有单次抽取和十次抽取入口

抽取中
  按钮进入 loading 态
  用户等待结果生成

结果揭示
  单屏展示一个像素宠物
  背景颜色表达品质或状态
  展示名称、标签、序号 1/10
  重复获得会转化成技能点

抽取记录
  列表沉淀最近获得结果
  可按类型切换，支持清空

回到主网格
  主网格更新拥有状态
  用户能明确感知刚刚生成了什么
```

可借鉴点：

- 结果揭示很聚焦：一屏只看一个物件，反馈清楚。
- 多结果用分页点串起来，用户知道自己正在看第几个。
- 重复结果不浪费，会转成另一类成长证据。
- 抽取记录让短反馈沉淀为可回看证据。
- 主网格能让用户快速看到“我已经有什么”。

不可照搬点：

- 不使用 `单抽 / 十连抽` 作为 Vitora 主路径。
- 不使用钻石、金币、价格、稀有度或概率。
- 不做宠物收集册、花园手册、成长册、图鉴入口。
- 不显示连续天数、完成率、红点或失败惩罚。
- 不把花朵阶段做成“奖励品质”，只能表达“建议反馈证据”。

## 2. Vitora 转译原则

视频里的 `抽取` 在 Vitora 中应转译成 `生成 / 揭示`：

| 视频机制 | Vitora 转译 | 边界 |
| --- | --- | --- |
| 单次抽取 | 完成一次反馈后揭示今晚种子方向 | 不随机刺激，不要价格。 |
| 十次抽取 | Cycle 中批量回看最近 7-10 次花架证据 | 不叫十连，不做抽取按钮。 |
| 稀有度背景 | 阶段背景：休眠 / 半开 / 盛开 / 成色更好 | 不写 SSR、稀有、普通。 |
| 重复宠物转技能点 | 同方向重复反馈转成“小雨点 / 置信度” | 小雨点不是货币。 |
| 抽取记录 | 建议反馈记录 | 不展示健康原文或 prompt。 |
| 主网格图鉴 | 周期花架证据横向卡组 | 不做 30 天网格或图鉴。 |

## 3. 目标闭环

Vitora 花园的闭环应是：

```text
Today 今日建议
  显示今日花朵、进度条、小雨点提示
  用户点“我试试”或“一键提醒”

白天轻提醒
  提醒确认产生待验证小雨点

今晚复盘
  先反馈有帮助 / 一般 / 不适合
  再选择恢复 / 留余量 / 轻动
  Vitora 揭示今晚生成的真实花种

次日 Today
  当前花朵和进度更新
  告诉用户“昨天什么反馈让它变化”

Cycle 周期
  展示最近 7-10 次花架证据
  用同气对比说明哪些建议更像用户
```

## 4. 关键交互规划

### 4.1 Today：轻量状态，不做抽取

Today 只显示“今天已经生成了什么”和“怎么照顾”，不出现抽取入口。

结构：

```text
智能监测

[身体翻译器状态 68/100]
[当前花] -> [预计更舒展]

[轻提醒 13:20 可调]       [白雏菊 68/100 · 半开]
[花园进度条 + 小雨点说明]

[午间补能 / 午后启动 / 傍晚舒展方案]
[换一换] [一键提醒]
```

交互：

- 点花朵或进度行：打开 `SeedStatusSheet`。
- 点 `一键提醒`：打开提醒 Sheet，顶部显示同一条花园进度。
- 点 `我试试`：生成当日意图和待确认小雨点。
- 不出现 `抽一次`、`十连`、`图鉴`、`花园入口`。

### 4.2 今晚复盘：用“揭示结果”替代“抽卡”

复盘完成反馈后才出现种子选择。

流程：

```text
反馈页
  有帮助 / 一般 / 不适合

方向页
  恢复 / 留余量 / 轻动

揭示页
  今晚种下：白雏菊
  花语：新开始、希望
  当前阶段：半开 68/100
  小雨点：来自今天的提醒确认和复盘反馈
  [保存给明早观察]
```

揭示页借鉴视频的一屏聚焦，但文案不使用“抽中 / 获得 / 稀有”。

视觉指标：

| 元素 | 指标 |
| --- | --- |
| 揭示 Sheet 高度 | 3/4 sheet 或中高弹层 |
| 主花朵 | 96-112pt 2D 低像素 |
| 背景 | 按阶段使用低饱和蓝绿/暖米/淡粉，不用稀有度强渐变 |
| 阶段标签 | 休眠 / 半开 / 盛开 / 成色更好 |
| 进度条 | 10pt，高亮 50/70/90 阈值 |
| 主按钮 | `保存给明早观察` |
| 次按钮 | `换一个方向`，仅返回三方向选择 |

### 4.3 Cycle：批量回看，不叫十连

视频里的十连结果可以转译为 Cycle 的 `本周期花架证据`。

结构：

```text
本周期花架证据
最近 7 次建议反馈生成的花

[白雏菊 半开 留余量]
[薰衣草 盛开 恢复]
[向日葵 成色更好 轻动]
...

同气对比
你今天：白雏菊 86 / 盛开
相近状态：白雏菊 72 / 半开
差异来自：轻提醒确认、反馈有帮助、留余量方向更贴近
```

点击单个花卡后打开证据详情：

```text
这朵花来自 5月20日 的午间补能建议
当时状态：黄体期 D18、能量 68
你反馈：有帮助
小雨点：2 滴
Vitora 学到：留余量方向比轻动更适合这类下午掉电
```

## 5. “重复获得”机制的 Vitora 版本

视频里重复宠物会转成技能点。Vitora 可以借鉴这个“重复不浪费”的感觉，但表达为学习证据。

规则：

| 情况 | 转化 |
| --- | --- |
| 连续多次选择同一方向且反馈有帮助 | 增加该方向的置信度 |
| 同一真实花种再次出现 | 不提示重复，显示“这个方向又被验证了一次” |
| 反馈一般 | 生成学习小雨点，提示“还需要再观察” |
| 反馈不适合 | 生成修正小雨点，提示“Vitora 会换方向” |

禁止：

- `重复获得，转化为 10 点`
- `已满级`
- `解锁技能`
- `稀有花升级`

推荐文案：

- `这次反馈让 Vitora 更确认：下午留余量比硬撑更像你。`
- `同样的方向又被验证了一次，白雏菊多了一滴小雨点。`
- `不适合也会留下修正水分，明天会换一个更轻的方向。`

## 6. 玩法状态模型

建议增加或整理这些状态，不一定都需要新表，优先复用 `SleepSeedCard`：

```swift
struct GardenRevealEvent {
    let id: UUID
    let date: Date
    let source: GardenRevealSource
    let flowerID: String
    let direction: SleepSeedKind
    let stage: FlowerGrowthStage
    let growthScore: Int
    let raindrops: [GardenRaindrop]
    let feedback: ReviewFeedback?
    let suggestionTitle: String
}

enum GardenRevealSource {
    case eveningReview
    case reminderConfirmation
    case cycleEvidence
}

struct GardenRaindrop {
    let source: GardenRaindropSource
    let value: Int
    let isConfirmed: Bool
}
```

P0 可以先不新增完整模型，只在 `SleepSeedCard` 中保留：

- `flowerID`
- `growthScore`
- `direction`
- `feedbackSummary`
- `raindropCount`
- `sourceSuggestion`
- `createdAt`

## 7. 实施优先级

### P0.1：先把反馈感做出来

- Today 保留紧凑花朵进度行。
- 提醒 Sheet 顶部显示同一条花朵进度。
- 复盘反馈后进入“今晚种下”揭示页。
- Cycle 花架证据展示最近 7-10 次。

### P0.2：加入视频式“结果揭示”

- 复盘三方向选择后，出现 1.2-1.6 秒低像素揭示动画。
- 花朵从小像素块拼成完整图。
- 显示阶段、花语、小雨点来源。
- 支持 `保存给明早观察`。

### P0.3：加入批量回看

- Cycle 的花架证据详情支持左右滑动。
- 顶部显示 `3/7` 这类序号点，但不写十连。
- 每张证据卡解释“建议 -> 反馈 -> 学到什么”。

## 8. 验收标准

- 用户在 Today 能一眼看到当前花朵、分数、阶段和小雨点。
- 复盘完成反馈后，能看到一屏聚焦的“今晚种下”结果。
- Cycle 能看到最近生成的花架证据，并能点开看来源。
- 没有第四个 Tab。
- 没有抽卡、货币、稀有度、商城、连续天数、完成率或任务失败。
- 所有视觉保持 2D 低像素风格。
- 不展示完整健康原文、prompt 或 AI 完整输出。
