# Cycle Page Spec

> 权威范围：Cycle 首页页面规格  
> 当前 baseline：`ios/QA/Screenshots/ImplementationV1/17-cycle-target-aligned.png`  
> 目标方向：`assets/design_04/cycle_d.png`

本文是 Cycle 页面的严格执行规格。范围锁定为“周期这个页面”的首页体验，不扩展成完整 Cycle 功能域重写。

## 1. 页面目标

Cycle 页面必须让用户理解：

```text
我现在处在什么长期节律背景里，以及这段周期如何影响近期能量动态。
```

页面不是日历页，不是任务页，不是医疗 dashboard，也不是商业化承接页。

## 2. 首屏结构

iPhone 17 Pro 首屏顺序固定为：

1. Header + left profile avatar + right share。
2. “这 30 天，Vitora 看见的三件事”总结卡。
3. Energy dynamics card。
4. 三张节律洞察卡。
5. 低权重 `本周期花架证据`。
6. Bottom Tab。

首屏必须建立 `周期回顾` 心智：三件事总结说明 Vitora 从周期里学到了什么，能量动态解释近期趋势。底部 Tab 不得遮挡能量卡叙事行或洞察卡。

## 3. Header

必须包含：

- 页面标题：`周期回顾`。
- 副标题：`复盘成长 · 洞察规律`。
- 左上用户头像玻璃圆按钮，进入 `我的 / 设置`。
- 右上分享玻璃圆按钮，分享当前周期卡片截图。

规则：

- Header 保持紧凑，不能做大 hero。
- 左上头像是用户/设置入口，不是 Pixel Vitora。
- 右上分享只生成当前可见周期摘要卡片，不导出记录原文、prompt、完整 AI 输出或隐藏健康数据。
- 触控区域不小于 44pt，视觉圆可以更小。

禁止：

- human avatar 当作 assistant IP。
- 把左上头像入口替换为 Pixel Vitora。
- 把分享做成 WebView、网页登录页或文本导出完整健康记录。
- 在 Header 下方常驻大型 Tip 或功能说明。

## 4. Removed Garden / Growth Hero

Cycle 首页不再展示成长册或花园包装。D-055 允许低权重 `本周期花架证据`，但它只能表达“建议 → 反馈”的学习结果，不能变成花田地图或成长册。

禁止出现：

- `30 天成长册`、`每天一张成长卡`、`8 / 30` 成长卡进度。
- 种下 / 发芽 / 花苞 / 盛开图例。
- 花园手册、种子选择、花田地图、每日成长卡网格。
- 任何任务、打卡、完成率、连续天数或未完成红点心智。

## 4A. Cycle Review Insight Card

必须包含：

- 标题：`这 30 天，Vitora 看见的三件事`。
- 副标题：`Vitora 已更新 5月8日 的理解`。
- 切换：`本周 / 趋势（月） / 周期`。
- 本周默认四行：
  - `低谷集中窗口`：`14:00-16:00`
  - `恢复较好时段`：`上午`
  - `影响因素`：`睡眠 + HRV + 周期`
  - `仍需校准`：`3 天待确认`

规则：

- 总结卡是 Vitora 的理解摘要，不是任务清单。
- 切换区使用卡片式连体页签，选中态为白色霜状玻璃页签和轻青色短线。
- `仍需校准` 用中性语气，不使用失败或催促。

## 5. Energy Dynamics Card

必须包含：

- 标题：`能量动态`。
- 日 / 周 / 月 segmented control，默认 `周`。
- 摘要：`本周平均 62% · 较上周 ↑5%`。
- 高 / 中 / 低 y 轴。
- 平滑单曲线，不堆多指标。
- 默认展示 `今天 68%` callout。
- 选中点和竖向虚线指示。
- 底部 Vitora 叙事行：`Vitora 看到：周三后恢复变慢`。
- 右侧 chevron。

视觉规则：

- 使用白色双态玻璃。默认 resting 为高白度磨砂玻璃；active/pressed 只增强白色 rim、近阴影和内部高光，不使用彩色卡片底。
- 图表主色 blue/cyan-first。
- 允许轻面积填充，但不可变成重色块。
- `↑5%` 可用低饱和成功色，不用红色焦虑表达。
交互规则：

- 单击卡片进入能量详情。
- 点选图表点可切换 / 展示 callout。
- 长按卡片打开 AskableSurface context menu。
- 图表点触控热区不小于 44pt。

禁止：

- 复制 Today 的“当前状态”卡心智。
- 堆睡眠、HRV、心率、周期多条医疗图表。
- 加商业化、高级分析锁、订阅提示。
- 用红色警报表达低谷或风险。

## 6. Feedback And Learning Layer

Cycle 的反馈与学习层由三件事总结、能量动态、节律洞察卡和低权重花架证据承担，不再通过成长册、完整花园或任务化种子系统表达。

允许：

- `这 30 天，Vitora 看见的三件事` 作为周期理解摘要。
- 能量动态详情内展示趋势、证据和 Vitora 叙事。
- 晚间复盘作为独立复盘路径回收 `有帮助 / 一般 / 不适合`。
- `本周期花架证据` 展示最近 7-10 张花卡，映射一次建议、反馈和 Vitora 学到的方向。

禁止：

- 显示连续天数、完成率、未完成红点、任务失败或“今天还没完成”。
- 把反馈做成成长册、花田地图、任务花园、成就系统或完成度。
- 每日调用 AI 生成图片作为 P0 实现路径。

## 7. White Dual-State Glass

Cycle 页面当前卡片容器优先使用白色双态玻璃：

```text
resting：高白度磨砂玻璃，白色 rim，柔光高光，轻阴影，基本看不到后方背景纹理。
active / pressed：同样无色，但边缘更亮、阴影更近、内部高光轻微收紧。
```

使用范围：

- 三件事总结卡。
- 能量动态卡。
- 能量详情图表和趋势 callout。
- 三张节律洞察卡和轻提示容器。

禁止：

- 卡片大面积彩色底。
- 彩色雾面背板。
- 强紫、强绿、橙红铺底。
- 为表达状态给整张卡染色；语义颜色只用于小点、线条、图标等低面积元素。

## 8. 轻提示

周期回顾首页不使用 `下拉进入花田地图`、`30 天成长册` 或种子选择作为 P0 入口。允许低权重状态文案，例如：

```text
仍需校准 3 天待确认
```

规则：

- 位于三件事总结卡内部或附近。
- 低权重，不抢主内容。
- 可带 `x`，但 P0 不要求真实 dismiss 持久化。

禁止：

- 每个组件旁边重复 Tip。
- 变成大教学卡。
- 强制用户完成教学后才能继续。

## 9. Pixel Vitora 使用规则

Cycle 页面内的 Pixel Vitora 只能用于：

- 阶段卡右下轻陪伴入口。
- 能量卡底部叙事行小 face。
- 底部 Tab 中央 Vitora face。

必须遵守：

```text
specs/004-vitora-swift-rebuild/pixel-vitora-ip/pixel-vitora-ip-spec.md
```

禁止：

- 每个页面单独重画一个 IP。
- smooth orb。
- human avatar / pet avatar / emoji face。
- 普通 SF Symbol、heart icon 或 chat icon 替代 Vitora face。
- 强紫霓虹、黑重阴影、任务养成表情。

## 10. 反向验收

出现以下任一情况，Cycle 页面直接不通过：

- Cycle 首页变成日历首页。
- 出现任务、打卡、完成率、连续天数、红点提醒。
- 出现成长册、花园手册、种子选择、花田地图、成长卡网格或完成进度。
- 出现 VIP、商业化、订阅卡。
- 出现复杂医疗 dashboard 或多指标趋势墙。
- 左上 profile/settings 被替换成 Vitora IP。
- 右上分享导出记录原文、prompt、完整 AI 输出或隐藏健康数据。
- Pixel Vitora 形象跑偏。
- 底部 Tab 遮挡能量叙事或 Tip。
- 文案制造医疗诊断、预测承诺或焦虑警报感。
