# Dynamic Aura Background Spec

## 目标

把目标视频里的“柔焦流体色场 + 周期色变体 + 低速漂移”转为 Vitora 首层背景系统。背景负责提供空间氛围和周期语义，不承载信息，不成为新的角色。

## 视觉结构

- 底层是 Warm Paper Aura：暖米纸 `#F4EEE8` 到珍珠提亮 `#FBF7F1`，不能是纯白 dashboard。
- 主形态是柔焦 S 型/旋涡流体色场和低饱和雾层，不是独立圆形光斑。
- 全 App 可使用原生 SwiftUI `PremiumAuraBackground` 分层实现：暖米纸底、右上 peach mist、左下 cyan mist、微纹理、底部暖灰雾。
- 运动幅度低，像空气中缓慢漂移，不像 loading、刷新或能量爆发。
- 玻璃卡后方必须自动压低饱和度和对比度，保证文字、图表和 Pixel Vitora 可读。
- Pixel Vitora 仍是唯一品牌 IP；背景不能出现球脸、眼睛、头像或宠物感形状。

## 周期变体

| Variant | 周期语义 | 颜色规则 | 禁止偏差 |
| --- | --- | --- | --- |
| default | 低数据/未知 | 暖米纸底 + 低饱和 cyan 空气层，接近 Vitora 基础品牌底 | 纯白、重紫 |
| menstrual | 月经期 | 浅粉 + 冷蓝，低饱和 | 红色警报、血色 |
| follicular | 卵泡期 | 蓝青 + 白雾，最清透 | 医疗冷蓝 dashboard |
| ovulation | 排卵期 | 薄荷绿 + 青色，绿色面积受控 | 荧光绿、大面积黄绿 |
| luteal | 黄体期 | 暖金 + 浅蓝，黄色只做柔光 | 橙红商业渐变、焦虑黄 |

## 动效规格

- 背景视频 10s 循环，30fps，低速漂移。
- 原生分层背景可用极低速 Canvas 雾层漂移，不依赖视频资产。
- 日期切换使用 240-320ms crossfade。
- Reduce Motion 开启时显示 poster frame，不播放视频。
- Reduce Transparency 开启时增加浅色 wash，降低背景存在感。
- 背景不响应点击，不产生触觉反馈。

## 禁用项

- 不能直接嵌入教程录屏。
- 不能出现设计工具 UI、浏览器、鼠标、文字、天气 App 内容。
- 不能用强紫霓虹、黑色重阴影、荧光绿、橙红大面积铺底。
- 不能每个页面单独发明背景逻辑。
- 不能直接使用外部参考图、人像或第三方产品 UI 作为背景素材。
- 不能牺牲玻璃卡和图表可读性。
- 不能改变 Pixel Vitora IP 形象。
