# Pixel Vitora IP Spec

> 权威范围：Pixel Vitora 的造型、材质、状态、道具、动效和禁用方向  
> 当前 baseline：用户 2026-05-14 提供的新柔体彩色小人参考图；App 内验收截图以本轮导出的 `34/35/36` 系列为准。

Pixel Vitora 是 Vitora app 内的品牌 IP。它不是普通 logo、不是圆形能量球、不是聊天头像，而是一个生活在 app 里的柔软彩色像素陪伴体。

## 1. IP 身份

Pixel Vitora 必须表达：

- 轻陪伴，不监控。
- AI assistant 在场，不是功能按钮集合。
- 柔和生命感，不做养成压力。
- 柔体彩色小人 blob 与低像素表情共存。

IP 必须服务 Vitora 的解释、校准、记录、建议、复盘和学习循环，不得被改造成任务、打卡、等级、连续天数或完成率角色。

## 2. 主体造型

主体必须是柔软、半透明、有空气感的彩色 blob companion。

必须包含：

- 非完美圆形的有机小人轮廓，像轻盈云团或软糖，有头部高点、侧边鼓包和底部软坠感，不是标准圆球。
- 半透明乳白磨砂外壳，边缘柔和但可识别。
- 内部彩色云雾：粉、橙、暖黄为中心暖光，青蓝和淡紫做边缘空气感。
- 柔白或银白 rim，不能是硬金属边。
- 左上柔光高光，表现半透明材质。
- 右下冷色透光，用于保持 Vitora 的清透品牌感。
- 底部软椭圆阴影，表现轻悬浮。
- 周围可有少量像素星点，但不能密集。

不得出现：

- 回退到蓝色圆形玻璃球。
- 纯 smooth orb。
- 无像素眼睛的普通能量球。
- 黑色大圆或重 3D 阴影球。
- 强紫色霓虹主体。
- 纯白 dashboard icon。
- 过硬玩具公仔或商业盲盒质感。

## 3. 颜色规则

| 层级 | 方向 |
| --- | --- |
| 主体色 | warm pink / orange / soft yellow first。 |
| 空气色 | cyan / lavender 只做边缘、底部和深处空气感。 |
| 外壳 | 乳白半透明，不能完全实心。 |
| rim | 白色、银白或浅灰白，柔和但可见。 |
| 阴影 | 粉橙柔光 + 软蓝阴影，不用黑重阴影。 |
| 眼睛 | 白色低像素块眼 + 少量暖光，必须比内部彩色云雾更亮。 |

实现时不能把紫色、蓝色或绿色做成第一眼主色；如果截图第一眼读成旧蓝球或强紫角色，验收不通过。

## 4. 表情系统

眼睛必须是白色低像素 block eyes。不能用 emoji、平滑线条、SF Symbol、普通圆点或拟人五官。

| 状态 | 表情规则 |
| --- | --- |
| `idle` | 两个低像素竖向块眼，稳定、轻呼吸。 |
| `listening` | 眼睛更亮，可轻微扩散，表达正在听。 |
| `thinking` | 像素眼可略有非对称，配合轻 shimmer / glow。 |
| `confirming` | 左侧低像素竖向块眼，右侧短像素表情，表达等待确认或给建议。 |
| `sleeping` | 低位闭合像素眼，软趴、低能量，用于睡眠或恢复语境。 |
| `energetic` | 眼睛更亮、轻上扬，表达精神较好或选中态。 |
| `questioning` | 轻微非对称像素眼，用于发问、想互动或等待用户补充。 |
| `blink` | 120-180ms，把竖眼压缩成短横像素后恢复。 |

表情可以扩展，但必须满足：

- 仍是 pixel block。
- 不拟人化到嘴巴、眉毛、emoji 表情。
- 不使用红色警报眼、哭脸、愤怒脸等压力表达。

## 5. 道具系统

道具是辅助 IP 场景的轻量挂件，不能抢主体。

允许的 P0 道具：

| 道具 | 用途 | 规则 |
| --- | --- | --- |
| `clipboard` | 今日建议、理解确认、记录确认。 | 半透明玻璃小板，蓝边或银白边，轻信息线，不直接用系统 doc icon 作为主体。 |
| `pencil` | 告诉 Vitora、校准、补充事实。 | 小尺寸轻量辅助，不变成主 CTA。 |
| `voice` | 语音入口或 listening 状态。 | 小型波形语义，可使用轻玻璃容器。 |

不得使用：

- 大任务板。
- 奖杯、等级、徽章。
- 红点提醒。
- 商业化/VIP 道具。
- 页面各自发明的新角色配件。

## 6. 动效系统

动效必须低幅、慢速、可读性优先。

| 动效 | 规格 |
| --- | --- |
| `breath` | 2.4-3.4s 低幅 scale / glow 循环。 |
| `float` | 2.4-3.4s 轻微上下漂浮，幅度小。 |
| `blink` | 随机 4-7s 一次，120-180ms。 |
| `sparkle` | 少量像素星点错位微闪，不密集。 |
| `confirmingAccessory` | clipboard 可跟随 3-6 度轻摆。 |

Reduce Motion 下：

- 关闭持续位移。
- 关闭随机眨眼。
- 关闭 shimmer 和强 glow 变化。
- 保留静态柔体彩色小人和白色低像素眼。

## 7. 页面使用规则

### 渲染材质变体

统一组件可以通过 `materialStyle` 切换场景强度，但不得改变角色方向或在页面内重画另一套 IP。

| 变体 | 用途 | 规则 |
| --- | --- | --- |
| `standard` | 默认 Pixel Vitora | 乳白霜态外壳为主，内部局部粉橙暖黄，少量青蓝淡紫边缘空气感。 |
| `heroCompanion` | Vitora Hero 夹层小人 | 放在文件夹背板与前景卡之间，低实体化、轻模糊、低 opacity，不遮挡文字。 |
| `messageAvatar` | 聊天气泡头像 | 36-38pt 圆角方形磨砂头像，只保留小范围暖色和分段低像素眼。 |
| `tabFace` | 底部 AI 管家 / Tab face | 小尺寸仍保持白色外壳和像素眼识别，glow 克制，不遮挡输入。 |
| `ambientBackground` | 背景氛围大 IP | 低透明度、大尺寸、仅作为空间生命感，不承担信息或按钮。 |

| 场景 | 状态 | 视觉强度 |
| --- | --- | --- |
| Today 顶部 | `idle` | 小尺寸、轻陪伴、右上品牌信号。 |
| Vitora 今日建议 | `confirming + clipboard` | 作为建议来源，不抢行动文字。 |
| Energy Reveal | `thinking` | 可更强 glow，但仍不常驻压住首页。 |
| 底部 Vitora Tab | `listening` selected / `idle` unselected | 低凸起，不遮挡内容和 input dock。 |
| Vitora Tab hero | `questioning / listening` 氛围层 | 去实体化、低透明、模糊，只作为文件夹卡背后生命感，不抢今日能量信息。 |
| Vitora message avatar | `messageAvatar` | 36-38pt 圆角方形磨砂玻璃头像，只保留彩色雾面和两个小像素眼。 |
| 输入栏聊天管家 | `energetic / listening` | 选中态小标识，配合上方柔白光源，不使用星星替代 IP。 |

### Message Avatar 变体

`messageAvatar` 是 Pixel Vitora 的紧凑聊天头像变体，用于 Vitora 留言气泡左侧。它必须继承统一 IP 的粉橙暖黄主体、乳白磨砂外壳和低像素眼，但为了保证聊天阅读清晰，不能放完整大 IP、星点、道具或大范围 glow。

必须包含：

- 微信式圆角方形外轮廓，圆角约为宽度的 28-32%。
- 半透明乳白磨砂玻璃底，边缘有轻银白 rim；乳白外壳必须比内部颜色更强。
- 内部只保留一小团淡粉橙暖光，青蓝淡紫只能在边缘极轻出现，不能形成强彩虹云雾。
- 两个小型白色低像素眼，亮度高于彩色云雾。
- 眼睛必须是分段 pixel blocks，建议每只眼由 2 列 x 3-4 行小方块组成；不能画成连续竖条、胶囊条或平滑圆点。

不得出现：

- 圆形头像。
- 完整大 IP 缩成小图导致糊成 icon。
- 星星、emoji、SF Symbol 或普通用户头像。
- 页面局部重新发明另一套头像。

## 8. 禁用方向

出现以下任一项，IP 验收不通过：

- 回退到旧蓝色玻璃球。
- smooth orb 替代 Pixel Vitora。
- 人类头像。
- 动物或宠物型 IP。
- emoji / 卡通脸。
- SF Symbol、heart icon、chat icon 直接代替 Vitora face。
- 黑色大圆、重 3D、强紫霓虹。
- 任务、打卡、连续天数、等级、完成率、红点。
- 每个页面单独发明不同 IP 形态。
- 道具比 IP 主体更强。
- 动效抢文字阅读或造成焦虑。

## 9. 验收标准

首屏人工验收必须能明确看到：

- 有机柔软 blob 轮廓，不是标准圆。
- 半透明乳白外壳。
- 粉橙暖光主体。
- 青蓝 / 淡紫边缘空气感。
- 白色低像素块眼。
- 左上柔光高光。
- 底部软阴影或悬浮感。
- Tab face 低凸起。

建议卡验收必须能看到：

- `confirming` 表情。
- clipboard 是辅助玻璃道具。
- 道具不抢建议文字。
