## 1. 全局交互模型

### 1.1 主导航

```text
┌────────────────────────────────────┐
│              当前页面内容            │
│                                    │
│                                    │
│        [今日][AI管家][周期]      [+]│
│ AI管家页：[语音] 我可以补充一... [发送]│
└────────────────────────────────────┘
```

| Rule ID | Rule |
| --- | --- |
| WF-G-001 | 主区固定为 `Today / Vitora / Cycle`。 |
| WF-G-002 | 全局 Dock 上排是居中的紧凑 Tab 组，右侧是独立圆形 `+` 记录键；非 AI 页不显示输入条；任意 sheet 展示时隐藏全局 Dock，sheet 使用本地输入。 |
| WF-G-003 | 从 Today / Cycle 对象或右侧圆形 `+` 唤醒 Vitora 时不切 tab，默认打开 3/4 contextual sheet。 |
| WF-G-004 | 只有用户点击 `AI管家` Tab 才进入完整 Vitora Assistant Surface，并展开/聚焦输入条。 |

### 1.2 Askable Surface 规则

```text
普通单击         → 进入该对象二层 IA
长按对象         → iOS context menu：问 Vitora / 告诉 Vitora 不准 / 查看详情
点图表数据点      → callout 小气泡，只解释局部点位
点 Vitora 动作    → 3/4 contextual sheet，带来源上下文
sheet 上滑       → 升级完整 Vitora context mode
```

| Rule ID | Rule |
| --- | --- |
| WF-G-005 | 单击详情永远是主路径，长按只是 shortcut。 |
| WF-G-006 | 首页不堆常驻“问 Vitora”按钮；AI 入口从真实对象自然发生。 |
| WF-G-007 | 首次发现长按能力用 TipKit 轻提示一次，成功使用后不再重复。 |
| WF-G-008 | 二层页面可用 `⋯` 作为长按能力 fallback。 |

### WF-T-002 · Energy Bowl + 周期线轴

关联：`REQ-005`, `UF-003`, `IA-011`

```text
默认：Today 首屏不显示顶部下拉 Energy Ball。能量碗是状态主交互，首页固定综合能量。

┌────────────────────────────────────┐
│              68%                    │
│          今日能量偏低 [查看数据]      │
│                                    │
│          宽口碗体下移，和文字保持距离    │
│                                    │
│       ╰────── ♥ ──────╯             │
│   排卵期       黄体期 D18       月经期 │
└────────────────────────────────────┘
```

验收：不使用系统 refresh 或顶部下拉 Energy Ball 语义；数字上方不放 `今天`，标签上方不放 `监测到`；能量数字是单层高对比渲染，无半透明偏移虚影；水滴从屏幕顶部安全区上方下落，进入碗口后有轻涟漪，碗内水位按综合能量显示浅水 / 半碗 / 接近满碗，Reduce Motion 下只显示静态水位；`今日能量偏低` 紧跟在 `68%` 下方，`查看数据` 位于状态词右侧同一行；首页不显示 `综合能量68% / 低谷14:00 / 负担偏轻` 数据小标签；能量碗图形和数字/查看数据/状态文案分层不重叠；点击能量碗进入状态详情；`查看数据` 进入今日分析/身体要素合并模块；首页不显示综合/睡眠/周期切换、不显示实时预测图、不显示校准 chips；碗下周期线轴无背景卡，必须下移到碗外下方并和碗底保持约一个中文字高度，形成中间下沉的三阶段圆弧，只展示前一段 / 当前段 / 下一段，当前 D18 显示 `排卵期 / 黄体期 D18 / 月经期`，所有阶段文字在圆弧下端。

## 11. QA 清单

- Today 首屏只由状态主路径组成：现在状态（综合能量碗 + 碗外周期线轴）、Vitora 今日建议、底部 Dock。
- Today 顶部日历能进入周期日历，Cycle 首页没有日历预览。
- Today 首页不出现顶部下拉 Energy Ball 或首页实时预测图；完整综合实时预测在今日分析可见。
- Vitora Tab 不是空聊天页，也不是功能 dashboard。
- 从 Today / Cycle 唤醒 Vitora 不切 tab，默认 3/4 sheet。
- Cycle 首页展示周期回顾、三件事总结、能量动态和节律洞察卡；不得出现 30 天成长册、花园手册或种子选择。
- 单击、长按、callout、TipKit、二层 `⋯` fallback 全部有验收路径。
- 所有首层卡片服从 `design-language-demo.md` 的 clear glass / aura background / Pixel Vitora 规则。
