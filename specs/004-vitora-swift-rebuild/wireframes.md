## 1. 全局交互模型

### 1.1 主导航

```text
┌────────────────────────────────────┐
│              当前页面内容            │
│                                    │
│                                    │
│        [今日][AI管家][周期]      [+]│
│ AI管家页：[语音] 我可以补充一... [发送]│
└────────────────────────────────────┘
```

| Rule ID | Rule |
| --- | --- |
| WF-G-001 | 主区固定为 `Today / Vitora / Cycle`。 |
| WF-G-002 | 全局 Dock 是一体式白色圆角凹槽 Dock：左侧 `今日`、右侧 `周期`，中心凹槽悬浮圆形 `+` 记录键；D-088 后 Dock 更贴近底部 safe-area 呈镶嵌感，中心 `+` 使用蓝绿色半透明霜态玻璃材质而非高饱和蓝紫实心球；D-090 后 Dock 本体、左右 Tab 胶囊和中心 `+` 都更紧凑，中心 `+` 颜色更透明，短按手动记录、长按语音记录；非 AI 页不显示输入条；任意 sheet 展示时隐藏全局 Dock，sheet 使用本地输入。 |
| WF-G-003 | 从 Today / Cycle 对象或 Dock 中心凹槽圆形 `+` 唤醒 Vitora 时不切 tab，默认打开 3/4 contextual sheet。 |
| WF-G-004 | 用户点击 `AI管家` Tab 进入完整 Vitora Assistant Surface，并展示独立输入快捷栏；键盘只在用户点击输入栏本身后聚焦。 |

### 1.2 Askable Surface 规则

```text
普通单击         → 进入该对象二层 IA
长按对象         → iOS context menu：问 Vitora / 告诉 Vitora 不准 / 查看详情
点图表数据点      → callout 小气泡，只解释局部点位
点 Vitora 动作    → 3/4 contextual sheet，带来源上下文
sheet 上滑       → 升级完整 Vitora context mode
```

| Rule ID | Rule |
| --- | --- |
| WF-G-005 | 单击详情永远是主路径，长按只是 shortcut。 |
| WF-G-006 | 首页不堆常驻“问 Vitora”按钮；AI 入口从真实对象自然发生。 |
| WF-G-007 | 首次发现长按能力用 TipKit 轻提示一次，成功使用后不再重复。 |
| WF-G-008 | 二层页面可用 `⋯` 作为长按能力 fallback。 |

## 11. QA 清单

- Today 首屏只由状态主路径组成：现在状态（综合能量碗 + 碗外周期线轴）、Vitora 今日建议、底部 Dock。
- Today 顶部日历能进入周期日历抽屉；Cycle 首页只允许 D-093 能量复盘日历，不允许任务/打卡日历。
- Today 首页不出现顶部下拉 Energy Ball 或首页实时预测图；完整综合实时预测在今日分析可见。
- Vitora Tab 不是空聊天页，也不是功能 dashboard。
- 从 Today / Cycle 唤醒 Vitora 不切 tab，默认 3/4 sheet。
- Cycle 首页展示能量复盘日历、`6.5` 指标卡和报告详情；不得出现 30 天成长册、花园手册、任务花园、种子选择、完成率或连续天数。
- 单击、长按、callout、TipKit、二层 `⋯` fallback 全部有验收路径。
