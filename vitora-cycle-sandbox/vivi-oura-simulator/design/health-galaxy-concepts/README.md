# 我的健康健康星系卡片方案

本目录包含 3 张 390x844 手机结构图，用来比较录屏里的“中心状态 + 周期轨道 + 多维节点”如何转译到 VIVI 的“我的健康”页面。

## A-health-galaxy-main-card.png

- 定位：替换当前健康页顶部的健康气泡图，作为主视觉入口。
- 展示内容：综合状态 82、最近 7 天趋势、睡眠 / 压力 / 恢复 / 活动 / 周期 5 个节点，以及 AI 身体翻译卡。
- 交互效果：点击节点后中心球变色、节点发光，下方 AI 身体翻译同步切换；点击整张星系卡进入全屏综合周期详情。
- 适合场景：想让“我的健康”页面最接近录屏里的星系感，同时保留 VIVI 的浅色潮汐风。

## B-cycle-orbit-report-card.png

- 定位：保留当前健康气泡图，在下方新增周期状态报告卡。
- 展示内容：顶部仍是健康节点状态；下方周期报告展示 7 天 / 28 天切换、周期轨道、睡眠均值、压力变化和恢复状态。
- 交互效果：点击气泡切换当前健康信号；点击周期报告卡进入周期详情；点击 7 天 / 28 天 chip 切换报告周期。
- 适合场景：更重视信息清晰度和周期报告入口，不希望主视觉改动太大。

## C-drawer-health-galaxy.png

- 定位：健康页内做抽屉式星系卡，默认不挤首屏。
- 展示内容：顶部只显示综合周期状态摘要；抽屉展开后显示健康星系、节点解释和短记录卡。
- 交互效果：上拉抽屉展开星系图；点击节点切换详情；长按节点显示解释；继续上拉可进入完整记录和周期历史。
- 适合场景：最适合手机端连续浏览，信息层级更轻，也更接近当前首页抽屉交互。

## 建议

优先选 A 做视觉方向，选 B 做产品信息结构，选 C 做最终手机交互参考。如果只实现一个版本，建议把 A 的星系主视觉和 C 的抽屉展开逻辑合并。
