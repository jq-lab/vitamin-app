# VIVI 声线调整标准与流程

## 1. 目标

VIVI 的声音不是普通播报音。声线要服务云朵 IP 和健康建议场景：听起来像有人在身边帮你看身体状态，而不是客服、系统通知或机械朗读。

核心标准：

- 真人感优先：自然停顿、短句、轻微呼吸感。
- 人设一致：不同声线可以不同，但都不能破坏 VIVI 的温柔、聪明、低刺激体验。
- 信息可信：健康建议要稳，不夸张、不制造焦虑。
- 可复用：每次新增声线都用同一套文案、参数和评分方式比较。

## 2. 声线角色矩阵

| 声线 | 角色定位 | 听感关键词 | 禁止方向 | 适合场景 |
| --- | --- | --- | --- | --- |
| 软萌小云朵 | 默认 AI 身体秘书 | 聪明、轻软、好奇、贴近 | 夹子音、幼态、过甜、客服腔 | 今日状态、AI 回复、轻提醒 |
| 男声 A · NOIR 低冷旁白 | 视频气质参考男声 | 低沉、冷白、克制、电影感 | 油腻、命令感、过度压嗓 | 情绪化开场、沉浸演示、夜间建议 |
| 男声 B · 青涩陪伴 | 年轻男中音 | 清亮、自然、轻陪伴 | 亢奋、卖萌、播音腔 | 日常建议、运动决策、轻鼓励 |
| 女声 · 知心大姐姐 | 成熟女性陪伴 | 温柔、可信、慢一点、安抚 | 客服腔、说教、过度亲密 | 睡眠恢复、压力提醒、周期建议 |

## 3. 台词导演标准

每条语音不要直接读 UI 文案。先按人设改成口语化台词。

通用规则：

- 一句话尽量不超过 18 个字。
- 长句拆成 2-4 个短句。
- 中文允许轻微语气词：`嗯`、`诶`、`我看一下`、`先别急`。
- 少用“主人”，默认不用。
- 少用书面词，比如“建议您”“根据数据判断”。
- 不做泛安慰，要把身体信号翻译成行动。

示例：

```text
原始 UI 文案：
今天状态不错，恢复条件比较稳。重要任务可以放在上午，但晚上仍然要留出恢复时间。

小云朵：
嗯，我在这儿。今天状态不错，昨晚的恢复托住了你。重要的事，我们先放在上午，慢慢往前推。

NOIR 男声：
嗯。今天的底子还不错。恢复托住了你。重要的事，放在上午。别急着证明什么。

知心姐姐：
今天状态是稳的。你可以把重要的事放在上午慢慢推进，晚上记得给自己留一点恢复时间。
```

## 5. 生成流程

1. 定义人设：声线名称、年龄感、情绪、禁止方向。
2. 写导演文案：在 `tools/tts-bakeoff/voice-director.mjs` 中为目标场景增加 variant。
3. 配置声线：在 `tools/tts-bakeoff/providers.mjs` 中新增 provider preset。
4. 生成样音：运行 `pnpm tts:bakeoff -- --provider edge_neural --text today_ready,sleep_recovery_weak,stress_attention,ai_reply_short --force`。
5. 打开试听台：访问 `voice-bakeoff/index.html` 或本地服务器。
6. 主观评分：按自然度、人格贴合度、机械感、中文舒适度打分。
7. 选择声线：在试听台点击“选择这个声音”，写入 `localStorage`。
8. App 接入：语音留言和 AI 助手优先读取已选声线。

## 6. 试听评分表

| 维度 | 通过标准 |
| --- | --- |
| 自然度 | 至少 4/5，不能像系统朗读 |
| 中文舒适度 | 断句自然，健康词不读错 |
| 人设贴合 | 至少 4/5，听感要符合角色设定 |
| 机械感 | 不超过 2/5 |
| 情绪控制 | 有情绪但不演过头 |
| 长时间耐听 | 连续听 3-5 条不烦、不腻 |

## 7. 后期处理标准

默认轻后期即可，不要把声音做成广告配音。

当前链路：

```text
highpass 65Hz
+ air EQ around 7600Hz
+ light compression
+ loudness normalization -16 LUFS
```

使用原则：

- 男低音可以保留一点低频，但要清理浑浊。
- 小云朵要保留空气感，但不要刺耳。
- 知心姐姐要平稳，不要压得太近。
- 所有最终样音响度保持一致，方便横向比较。

## 8. 兜底策略

- 有授权 ElevenLabs / MiniMax voiceId：优先真实模型生成。
- 没有 Key：只显示 Edge 本地可听预览，并明确标注“非最终主模型”。
- 真实模型失败：页面禁用选择，不用系统 TTS 冒充。
- App 播放失败：显示文字和波形 mock，不播放机械系统音。

## 9. 新增声线 Checklist

- [ ] 声线有明确人设和禁止方向。
- [ ] 至少覆盖 4 条场景样音。
- [ ] 同一文案可以横向对比其他声线。
- [ ] 文件大于 10KB，时长大于 1 秒。
- [ ] 试听页可以播放并选择。
- [ ] 选择结果能被 App 语音留言读取。
- [ ] 文档记录参数、provider、voiceId 和评分结果。
