Vitora IA 可视化截图目录

对象是 vivi-oura-simulator 当前 Expo / React Native + WebView 可交互原型；这不是原生 Swift 新实现，也不是生产级健康产品。

36已接入 HTML 的真实模拟器截图
3主导航：今日、探索、健康
1剩余 WebView onboarding 遗留层未验证

截图原则：只接入真实 iOS Simulator 渲染出来的页面截图；被系统键盘教学、异常画面、错误路由或重复页面污染的截图已清理。

覆盖方式：主 Tab 和普通路由按真实 app 运行路径截取；Profile 子面板、弹层、Alert 和部分 click-only 状态通过临时 QA deep link 打开后截图，因为本轮 Simulator 的辅助点击多次显示成功但没有稳定触发 RN Pressable。临时 QA 路由只用于取证，截图完成后会从源码撤回。
